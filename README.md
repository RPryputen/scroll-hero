# Hero block с анимацией по прокрутке

Тёмный «премиальный» hero-блок для сайта об автоматизации бизнеса с ИИ.
Вся анимация привязана к прокрутке, без внешних библиотек и шрифтов —
достаточно открыть `index.html` в браузере.

## Структура

```
├─ index.html          # разметка hero + секции-заполнители для теста скролла
├─ css/style.css       # стили и вся раскадровка анимации через var(--p)
└─ js/
   ├─ constellation.js # canvas-фон: точки и линии-«созвездия»
   └─ main.js          # прогресс скролла → CSS-переменные, параллакс, reveal
```

## Как работает анимация

`.hero-scene` высотой `260vh` задаёт длину раскадровки, сам `.hero` залипает
на `100vh` через `position: sticky`. `js/main.js` считает прогресс прокрутки
внутри сцены (`0…1`), сглаживает его через lerp и пишет в CSS-переменную `--p`.
Дальше всё считает CSS в `calc()`:

- кристалл увеличивается, поворачивается и растворяется;
- карточки CRM / Chat-bot разлетаются в стороны с поворотом;
- слова заголовка уезжают вверх со stagger-задержкой (`--i`) и размываются;
- фон-созвездие уходит в параллакс, свечение расширяется;
- первая секция наезжает поверх закреплённого hero.

Дополнительно: параллакс от курсора (`--mx` / `--my`), полоска прогресса
страницы, сжимающийся header, появление секций по `IntersectionObserver`.

## Настройка

| Что менять | Где |
| --- | --- |
| Скорость раскадровки | высота `.hero-scene` в `css/style.css` |
| «Вязкость» движения | константа `EASE` в `js/main.js` |
| Дальность разлёта карточек | множители в `.card--crm` / `.card--chat` |
| Плотность фона | `LINK_DIST` и `count` в `js/constellation.js` |

Учтён `prefers-reduced-motion`: при включённой настройке анимации отключаются,
hero становится обычным экраном на `100vh`.

Кристалл нарисован SVG-полигонами, поэтому его можно заменить на картинку —
достаточно вставить `<img>` внутрь `.crystal`, остальная логика не изменится.
